
Many students glorify the idea of cramming, framing it as the pathway to success. In reality, this approach typically leads to inefficient learning, reduced retention, and cognitive fatigue, which is a detriment to long term performance. The purpose of this study is to develop and test an EEG system capable of identifying cognitive fatigue in academic tasks among students and to assess the potential of real-time fatigue detection to enhance study and rest cycles. This project also serves as a proof of concept for broader neurorehabilitation applications where monitoring cognitive load, paired with motor data, could optimize rehabilitation cycles for stroke patients.

We collected our EEG data from 6 student participants executing rigorous cognitive tasks using the Muse 2 headband. We extracted 5 different wave frequencies from each of the 4 electrodes.

Across participants, the Engagement Index (Beta / (Alpha + Theta)) showed consistent downward trends during sustained cognitive tasks. Using a threshold of mean – 1.5 SD, the system successfully identified prolonged periods of reduced engagement across multiple sessions. These patterns were reproducible across participants, suggesting the signal reflected cognitive fatigue rather than random variability.

The findings demonstrate that consumer-grade EEG data can be processed to detect meaningful shifts in cognitive engagement during academic tasks. Although the system currently operates retrospectively, it provides a strong proof of concept for individualized, brain-informed study optimization and future real-time fatigue detection systems.
